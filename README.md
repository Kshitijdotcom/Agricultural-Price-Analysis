# Agricultural Market Price Analysis Dashboard

## Project Overview

This project analyzes agricultural commodity prices across India using Power BI. The objective is to identify pricing patterns, compare commodities across states, and build an interactive dashboard that supports data-driven decision-making.

---

## Objectives

- Analyze commodity prices across different Indian states.
- Compare average prices for major commodities.
- Visualize geographic price distribution.
- Build an interactive dashboard using Power BI.

---

## Dataset

- Source: Agricultural Market Price Dataset
- Date: 19 May 2025
- Number of States: 16
- Number of Commodities: 145

---
